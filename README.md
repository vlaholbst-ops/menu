# Меню на две недели

- Одна готовка на ужин и следующий обед. Карточки показывают одинаковые блюдо, гарнир и размер порции. Пятничная курица на шаурму идёт и в субботний обед. Лаваш собирается перед едой.
- Закупки и остатки рассчитаны на две порции ужина, а раскладка показывает, что отложить на завтра и что заморозить. Если начинаешь меню в середине цикла, проверь, какие заготовки уже есть.
- КБЖУ приблизительные. Для гранолы, куриной сосиски, варенья и соусов уточни значения по упаковке. Выход курицы зависит от приготовления. Вес готового гарнира указан отдельно от веса сырья.
- Отметки и комментарий хранятся на устройстве по дате. Чтобы сохранить вчерашний день, выбери его в поле «Дата записи в журнал». Даты соответствуют дням 14-дневного цикла.
- Для синхронизации открой личную ссылку на меню на каждом устройстве. Браузер запомнит отдельный Google-журнал питания и покажет кнопку «Журнал питания». «Синхронизировать день» пишет четыре строки в лист `Питание`.

## Сверка загруженных рецептов

| Блюдо из подборки | Где в меню |
| --- | --- |
| Творожные вафли | Неделя 1, ПН, и неделя 2, ЧТ |
| Маковые панкейки | Неделя 1, СР, и неделя 2, ВТ |
| Курица с фунчозой | Неделя 2, ВС → неделя 1, ПН |
| Сырники | Неделя 2, СБ |
| Омлет с ветчиной и сыром | Неделя 1, ВТ |
| Шоколадные вафли | Обе недели, ПТ |
| Куриные котлеты с брокколи и морковью | Неделя 1, СР → ЧТ, и неделя 2, ПТ → СБ |
| Куриный «бочонок» с грибами | Неделя 1, ВС → неделя 2, ПН |
| Куриные тефтели | Обе недели, ВТ → СР |
| Лепёшка из лаваша с ветчиной и сыром | Неделя 1, СБ, и неделя 2, СР |
| Шаурма | Неделя 1, ПТ → СБ |
| Куриный шашлык из бедра | Неделя 2, СБ → ВС |
| Омлет с куриной сосиской и картофелем | Неделя 2, ВС |
| Рубленые котлеты на гхи | Неделя 2, ПН → ВТ и ЧТ → ПТ |

Бутерброды с тунцом, авокадо и яйцом из базы питания включены в завтрак воскресенья первой недели.
