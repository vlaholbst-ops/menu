# Меню на две недели

Статический планировщик питания Владимира.

- `index.html` — 14-дневный цикл из двух разных недель, 4 приёма пищи, раскрываемые рецепты и отметки съеденного.
- После комментария к каждому дню показаны покупки, продукты из запаса и остатки с указанием, в какой следующий день они используются.
- Для расчёта заложены упаковка куриного филе 900 г, филе бедра 500 г и партии фарша по полному рецепту; готовые лишние порции замораживаются.
- Кнопка «Синхронизировать день» пишет четыре строки в лист `Питание` личного Google-журнала; при первой записи лист создаётся автоматически.
- Опубликованная версия: https://vlaholbst-ops.github.io/menu/.

Проверка: `node test.mjs`.
