# Меню на неделю

Статический планировщик питания Владимира.

- `index.html` — 7 дней, 4 приёма пищи, раскрываемые рецепты и отметки съеденного.
- Кнопка «Синхронизировать день» пишет четыре строки в лист `Питание` личного Google-журнала; при первой записи лист создаётся автоматически.
- Опубликованная версия: https://vlaholbst-ops.github.io/menu/.

Проверка: `node test.mjs`.
